# Progress entries

One file per task since WP-5 (28 October 2026), named by the task's ID: `WP-5.md`, `BF-17.md`, `P3.3-3.md`. `/finish-task` writes it as the task PR's last commit, with the PR number, so two open PRs never edit the same file.

Each file holds one entry in the template from [PROGRESS.md](../PROGRESS.md) ("Entry template"), at most 10 lines (WP-4). A task that needs a second entry (for example a PR in parts, as P3.5-1 was) adds to its own file.

The entries written before WP-5 stay in `PROGRESS.md`'s Log section. `/next-task` takes the newest entry to be the file most recently added to this folder in `development`'s history.
