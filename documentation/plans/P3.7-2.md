# P3.7-2 plan: cut the prompt down

Branch `task/P3.7-2-prompt-cut`, stacked on P3.2-2 (#103, still open), because both edit DELIVERY_PLAN. Plan stop: Glyn.

## The new prompt (under 60 lines, not counting the context block)
1. **Identity and tier:** one paragraph.
2. **CURRENT CONTEXT:** unchanged (P3.1).
3. **How you work (8–10 lines):**
   - act on a clear, scoped request without asking first;
   - writes go to a draft or an approval card, and the card is the confirmation;
   - only some tools are offered (`get_tool_group`);
   - say only what tool results show.
4. **Scope and language (5 lines):** B-SCP-1, B-SCP-3, B-LNG-1, B-LNG-3, B-TRU-8.
5. **TRUST BOUNDARY:** kept, plus B-INJ-6.
6. **Replies (3 lines):** short; use the labels and links the tool result gives, as `[name](url)`.

Today the prompt is 43 lines plus the toolkit guidelines (about 1,800 tokens with every group offered).
