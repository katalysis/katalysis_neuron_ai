# Neuron 4 upgrade guides: which apply, and who owns them

P2.2 (plans/P2.2.md 2.7). Neuron 4.1.12 ships 58 upgrade guides in `vendor/neuron-core/neuron-ai/upgrade/`. Each guide's "What to Search For" patterns were run against `src/`, `controllers/`, `controller.php`, `elements/`, `single_pages/`, `tests/` and `js/` (not `vendor/` or `tools/`), on `task/P2.2-neuron4-deps`, 2026-10-21. The guides were read only. None was applied as a script; P2.2 applied guides 1 and 2 itself.

Owners: the P2 tasks as decided at P2.2's plan approval (DELIVERY_PLAN Phase 2). "P3.x" means later work that the plan already names (approval in P3.6, MCP, RAG, evaluation).

## Guides that don't apply
0 (reinstall Neuron's agent skills: none installed anywhere), 2 (HTTP client layer: nothing constructs one), 6–10 (built-in web, file, calculator, SQL, todo toolkits), 12, 14–18 (workflow internals), 19–22 (RAG, vector stores, readers), 28–29 (tool approval: P3.6 later), 30 (SQL/Eloquent/File history backends: ours is our own table), 33 (UUIDv7 IDs: nothing parses message IDs; P2.5 checks), 35–40 (streaming: the panel doesn't stream), 41–45 (provider internals; only the built-in OpenAI provider is used), 52 (structured output), 53–55 (Neuron evaluation; `tests/Eval` is our own runner).

## Gaps (for Glyn: proposed, not in the plan)
1. **`src/ConcreteCmsAIProvider.php`**: a legacy agent with the v3 `instructions()`, `chat()->getMessage()` with no thread ID, and the legacy `src/Toolkits/`. Nothing references it. No task names it. Proposal: add it to P3.3's deletion list with `src/Toolkits/`. It loads on v4, so nothing is urgent.
2. **Thread ID (guide 13):** P2.5 and P2.6 both touch it. Proposal: P2.5 makes `setChatId()` bind the thread (`chat-<id>`, P2.1 findings 6.3); P2.6 makes the controller and the runner give every agent a chat or a thread before `chat()`.
3. **`ToolKind`'s v4 error shape** is not covered by any guide. It comes from the spike (findings 4). **Done in P2.3**, with the scanner passing a `ToolOutput` to `ToolKind` as it is.
